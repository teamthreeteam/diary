# <타입> : <제목> 의 형식으로 작성합니다.

# ✨feat    : 새로운 기능 추가
# 🐛fix     : 버그 수정
# 💡chore   : 빌드 업무, 패키지 매니저, 주석 수정, 오타 수정 등
# 📝docs    : 문서 수정 (README 등)
# ♻️refactor: 코드 리팩터링
# ✅test    : 테스트 코드 추가
# 🚚build   : 빌드 관련 파일 수정/삭제
# 🚑hotfix  : 긴급 수정

# Example
git add .
git commit -m "feat : Google, Kakao 소셜 로그인 기능 추가"
git push origin develop
